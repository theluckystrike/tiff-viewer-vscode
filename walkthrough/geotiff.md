# GeoTIFF

When a page has GeoTIFF tags, the panel shows a GeoTIFF section.

- CRS as an EPSG code, pixel size and units, and the bounds of the image.
- The nodata value. Nodata pixels are left transparent and skipped in the statistics.
- Every GeoKey, with names for model type, raster type and units.

Move the pointer over the image to read the value and the map coordinate of that pixel in the status bar.
